# Number Guessing Game

A Python command-line game for the CodeOrbit Tech Python Programming Internship.

## Features
- Random number from 1 to 100
- "Too high" and "Too low" hints
- Tracks valid guessing attempts
- Allows multiple rounds
- Handles non-numeric input

## Run
Open the folder in VS Code, choose **Terminal → New Terminal**, and run:
`python number_guessing_game.py`
On Windows, try `py number_guessing_game.py` if needed.

## Tests
Make guesses until the correct number is found; check the hint and attempt count. Enter `y` for another round and `n` to exit. Try letters to test invalid-input handling.
